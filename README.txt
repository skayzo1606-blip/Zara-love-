WEBSITE ULANG TAHUN ZARA — VERSI TANPA PENGUNCI

Isi: index.html dengan countdown tetap tampil tetapi semua halaman bisa dibuka kapan saja, galeri foto geser, playlist YouTube A Thousand Years — Christina Perri, halaman Journey/Moment/Playlist/Gift.

PENTING FOTO:
HTML merujuk file foto berikut yang harus ada di folder yang sama dengan index.html di repository GitHub:
- IMG-20260923-WA0008.jpg
- IMG-20260922-WA0039.jpg
- IMG-20260926-WA0015.jpg
- IMG_20260817_215817.jpg
- foto-1.jpg

Jika nama file di repository berbeda walau satu huruf, foto tidak akan muncul. Upload foto-foto itu di root repository (selevel dengan index.html), atau sesuaikan src pada index.html dengan nama file yang tepat.

MUSIK:
Playlist memakai embed YouTube: https://www.youtube.com/watch?v=rtOvBOTyX00 . Pengunjung mungkin perlu menekan Play.

UPLOAD:
1. Buat repository baru yang Public.
2. Upload index.html dan kelima file foto ke root repository (jangan masukkan index.html ke dalam subfolder).
3. Commit changes.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Tunggu proses publish; GitHub Pages bisa perlu beberapa menit.

Versi ini sengaja TIDAK mengunci halaman; countdown hanya ditampilkan sebagai penghitung waktu.
